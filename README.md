
#  RentSpot — Аренда спортивного инвентаря между людьми

**RentSpot** — это frontend-приложение для шеринга спортивного инвентаря. Удобная платформа, где люди могут сдавать и брать в аренду коньки, лыжи, сноуборды, велосипеды, ролики и самокаты.
---

## Идея проекта

У многих дома пылится спорт инвентарь, используемый раз в год, находящийся на грани отправки в мусорку. RentSpot решает эту проблему, создавая удобное пространство для шеринга, и заработка на ненужных вещах прямо в браузере.

---

##  Возможности

### Профиль пользователя
- Создание и редактирование профиля (имя, email, телефон, город, фото)
- Валидация всех полей в реальном времени
- Drag & drop загрузка аватара

###  Управление объявлениями 
- Создание объявления с фото товара
- Редактирование и удаление своих объявлений
- Обязательное фото товара + валидация
- Хранение в `localStorage`

###  Лента объявлений
- Поиск по названию и локации (мгновенно)
- Фильтр по категориям
- Сортировка: по дате, цене ↑↓, алфавиту
- Адаптивная сетка (3-2-1 колонок)

###  Чат между пользователями
- История переписки в `localStorage`
- Список чатов с последними сообщениями
- Непрочитанные сообщения
- Удаление чата через контекстное меню (ПКМ)
- Адаптивная вёрстка под мобильные устройства

###  Полная адаптивность
| Устройство | Особенности |
|------------|-------------|
| Desktop (≥1024px) | 3 колонки, боковые панели |
| Tablet (768-1023px) | 2 колонки |
| Mobile (<768px) | 1 колонка, FAB-кнопка |

###  Тёмная тема
- Переключение через кнопку в шапке
- Сохраняется в `localStorage`
- Единая на всех страницах

###  Карта
- Визуальное отображение местоположения
- Адаптивный iframe-виджет

##  Технологии

| Категория | Технологии |
|-----------|------------|
| Frontend | HTML5, CSS3, JavaScript (ES6+) |
| Стилизация | Flexbox, Grid, CSS Variables, адаптив |
| Хранилище | LocalStorage, SessionStorage |
| API | [randomuser.me](https://randomuser.me) — аватары и имена |
| Карты | Яндекс.Карты (iframe-виджет) |
| Шрифты | Google Fonts (Inter) |
